# HairInk Solutions

USA portal for hair transplant problems, SMP, tattoo, and paramedical camouflage services.

## GitHub Pages (recommended)

1. Create a new GitHub repository.
2. Upload **all files** from this zip (or push with git).
3. Repo **Settings → Pages → Source**: Deploy from branch `main` (or `master`), folder `/ (root)`.
4. Open the Pages URL. The site is a single-page app (`index.html`).

## Local run (optional)

```bash
node server.js
```

Open http://localhost:3000
